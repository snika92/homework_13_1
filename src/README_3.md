**Задание 2**
Для класса Product необходимо добавить возможность складывать объекты между собой таким образом, 
чтобы результат выполнения сложения двух продуктов был сложением сумм, умноженных на количество на складе.

Например, для товара a с ценой 100 рублей и количеством на складе 10 и товара b c ценой 200 рублей и количеством 
на складе 2 результатом выполнения операции a + b должно стать значение, полученное из 100 × 10 + 200 × 2 = 1400.
